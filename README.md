# Fake GPS (Android)

మ్యాప్‌పై ఎంచుకున్న చోటును ఫోన్ GPS లొకేషన్‌గా చూపించే యాప్. Android 6.0 మరియు ఆపై వెర్షన్లకు.

## APK తయారు చేయడం

### GitHub ద్వారా (కంప్యూటర్ అవసరం లేదు)

1. github.com లో కొత్త repository సృష్టించండి.
2. ఈ ZIP లోని అన్ని ఫైళ్లను, `.github` ఫోల్డర్‌తో సహా, అదే అమరికలో అప్‌లోడ్ చేయండి.
3. **Actions** ట్యాబ్‌లో **Build APK** పూర్తయ్యే వరకు ఆగండి.
4. ఆ రన్ కింద **Artifacts** లోని `FakeGPS-apk` డౌన్‌లోడ్ చేసి, ZIP తెరిచి APK ఇన్‌స్టాల్ చేయండి.

### Android Studio ద్వారా

ఈ ఫోల్డర్‌ను Android Studio లో తెరిచి **Build > Build APK(s)** నొక్కండి.

## ఫోన్‌లో సెటప్

1. **Settings > About phone** లో **Build number** పై 7 సార్లు నొక్కండి.
2. **Developer options > Select mock location app** లో **Fake GPS** ఎంచుకోండి.
3. యాప్ తెరిచి, లొకేషన్ అనుమతి ఇవ్వండి.
4. మ్యాప్‌పై ఒక చోటు నొక్కి **ప్రారంభించు** నొక్కండి.

ఆపడానికి యాప్‌లో లేదా నోటిఫికేషన్‌లో **ఆపు** నొక్కండి.
